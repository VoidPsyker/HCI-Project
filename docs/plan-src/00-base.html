Emotion-Contingent Navigation

A preregistered plan for comparing six menu structures across four emotional contexts — and for testing whether switching structure actually helps.
This document turns the emotional adaptive navigation idea into a testable programme: a pilot, a 6 × 4 mapping study, a causal adaptation study, and an end-to-end system evaluation with an imperfect emotion estimator. It includes the full protocol, measures, analysis plan, sample-size rationale, prototype architecture, ethics, and a paper outline.

How to use this document

Sections 1–6 define the scientific logic. Sections 7–10 are the three study protocols. Sections 11–13 specify measurement and analysis. Sections 14–17 cover build, ethics, validity, and schedule. Section 18 gives the paper skeleton. The appendices contain task examples, questionnaire items, induction scripts, the event schema, randomisation matrices, and analysis code skeletons. If you have limited time, read §0, §2, §3, §4, §8, §9, §13, then use Track A/B/C in §17.
